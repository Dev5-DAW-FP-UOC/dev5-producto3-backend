# Instalation

## Instalacion de Node.js
 Esto se hace antes solo una sola vez, esto es en el caso de mac Os se instala desde la pagina oficial https://formulae.brew.sh/formula/node
 
```sh
brew install node
```

## Creo la carpeta en mi Workspace para el proyecto y se abre con VS code se abre el terminal y se ejecuta este comando (crea el package.json)
```sh
npm init -y
```
## Se crea el archivo index.js

ejemplo (console.log('Hola mundo'))

Se ejecuta en la terminal el comando para visualizarlo

```sh
node index.js
```

## Se instala Express
```sh
    npm i express
```

## Se modificó el package.json 

"type": "module",
Es para usar el import no el require versiones antiguas 

## Se instala Graphql sobre Espress

```sh
    npm install graphql express-graphql
```
